# Проект для автоматизации тестирования с использованием Pytest и Allure

## Описание

Этот проект предназначен для автоматизации тестирования веб-приложения с использованием Pytest и Allure. Он включает в себя тесты для проверки функциональности страницы входа и корзины покупок.

## Установка

1. Установите зависимости:

```pip install -r requirements.txt```


2. Установите Allure Command-Line Tool, следуя инструкциям на [официальном сайте Allure](https://github.com/allure-framework/allure2/releases).

## Запуск тестов

1. Запустите тесты с генерацией отчетов Allure:

```pytest --alluredir=allure-results```


2. Сгенерируйте отчет:

```allure generate allure-results --clean```


3. Откройте отчет в браузере:

```allure open``` 


## Структура проекта

- `pages/`: содержит классы PageObject
- `test_run.py`: содержит тесты
- `conftest.py`: содержит фикстуры и настройки
- `requirements.txt`: список зависимостей
- `allure.yml`: конфигурация Allure

## Дополнительная информация

- Проект использует Pytest для написания и запуска тестов
- Allure используется для генерации отчетов о тестировании
- Selenium WebDriver используется для взаимодействия с веб-интерфейсом
